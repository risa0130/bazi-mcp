# 三命通会に基づく命式鑑定リファレンス | 三命通会命理解读参考 | Sanming Tonghui Interpretation Reference

本ドキュメントは、明代・万民英著『三命通会』（12巻）を中心とする古典命理の解読原則を、
`getBaziDetail` が返す八字データに対して適用するためのリファレンスです。

This document distills the interpretation principles from the classical *Sanming Tonghui*
(《三命通会》, Ming dynasty, by Wan Minying) into an actionable framework for reading
any bazi chart returned by `getBaziDetail`.

MCPサーバ側は計算だけを行い、鑑定（解釈）はクライアントLLMがこの文書を参照して実施します。
The MCP server only computes raw data; interpretation is performed by the client LLM using this reference.

## 1. 鑑定の全体手順 | Overall Procedure

三命通会の鑑定は、以下の順序で進めるのが原則です。

1. **排盤 (Chart casting)**: `getBaziDetail` で年月日時の四柱・大運・神煞を取得。
2. **日主の強弱判定**: 日干を「旺相休囚死」で位置付ける。
3. **格局の取用**: 月令 (月支蔵干) を優先し、内格・外格を決定。
4. **用神の選定**: 格局と日主の強弱を踏まえ、扶抑・調候・通関・病薬のいずれで用神を取る。
5. **喜神・忌神の整理**: 用神を生助するのが喜神、剋制するのが忌神。
6. **刑冲合会・神煞の吟味**: 命局全体の相互作用を確認。
7. **大運・流年の推移**: 用神・喜神が透ける運が吉、忌神が旺じる運が凶。
8. **六親・事象の推断**: 財官印・宮位・神煞を組み合わせ、配偶・子女・仕事・健康・財を判断。

> **原則 | Principle**: 「先看日主強弱、次看月令、再看格局、後定用神」
> "First judge Day Master strength, then the month command, then the structure, and finally the useful god."

## 2. 日主の強弱判定 | Day Master Strength

日干（`日主`）の強弱は五要素で総合的に判定します。

### 判定要素

| 要素 | 内容 |
| --- | --- |
| **得令** | 月支が日干を生助するか。最も比重が大きい (概ね30–40%)。 |
| **得地** | 年支・日支・時支に日干の根 (通根) があるか。 |
| **得勢** | 天干・地支蔵干に比劫・印星が多いか。 |
| **得生** | 印星 (正印・偏印) が透干し、日干を生じるか。 |
| **得助** | 比肩・劫財の助けがあるか。 |

### 十二運星による位置付け

`getBaziDetail` の各柱に含まれる `星运` (長生・沐浴・冠帯・臨官・帝旺・衰・病・死・墓・絶・胎・養) を参照。
月支の星運が **臨官・帝旺・冠帯** → 得令、**長生・養** → 中和、**衰・病・死・墓・絶** → 失令。

### 旺相休囚死

| 状態 | 意味 | 例 (日干=甲木) |
| --- | --- | --- |
| **旺** | 同五行の月 | 春 (寅卯月) |
| **相** | 生じられる月 | 冬 (亥子月) |
| **休** | 生じる月 | 夏 (巳午月) |
| **囚** | 剋する月 | 秋 (申酉月) の反対、冬…※木を剋するのは金 |
| **死** | 剋される月 | 秋 (申酉月) |

### 総合判定

- **身強 (身旺)**: 得令かつ通根＋比劫多 → 財官を用いる。
- **身弱**: 失令かつ根なし → 印比で生助を用いる。
- **中和**: どちらでもない → 格局の順逆で用神を選ぶ。

## 3. 格局の判定 | Structure (Ge Ju) Determination

### 3.1 月令蔵干を優先

月支の蔵干 (本気→中気→余気の順) が **天干に透干している** ものを最優先で格局とします。

| 月令に透干している十神 | 内格名 |
| --- | --- |
| 正官 | 正官格 |
| 七殺 | 七殺格 (偏官格) |
| 正財 | 正財格 |
| 偏財 | 偏財格 |
| 正印 | 正印格 |
| 偏印 | 偏印格 (梟神格) |
| 食神 | 食神格 |
| 傷官 | 傷官格 |
| 比肩・劫財 (月令が同気) | 建禄格 / 月刃格 (羊刃格) |

> **例**: 日主 己土、月支 未 (蔵干 己・丁・乙)。天干に「丁」が透けていれば **偏印格**、「乙」が透けていれば **七殺格**。透干がなく本気「己」しかない場合は **建禄格**。

### 3.2 格局の順逆

- **順用 (格を生助する用神)**: 正官・正財・正印・食神 → 生・護・扶する。
- **逆用 (格を剋制する用神)**: 七殺・傷官・偏印・羊刃 → 制・化・合する。

### 3.3 破格の要因

- 官格を傷官が剋す
- 印格を財が破る
- 食神格を偏印が奪う (梟神奪食)
- 財格を比劫が争う

破格の場合は救応神 (救いの十神) を探し、大運で補われれば「破而復成」となる。

## 4. 用神・喜神・忌神 | Useful / Favorable / Unfavorable Gods

### 用神取用の4原則

1. **扶抑 (ふよく)**: 身弱なら生助、身強なら剋洩する。最も基本。
2. **調候 (ちょうこう)**: 寒暖燥湿の偏りを是正 (第6章参照)。
3. **通関 (つうかん)**: 対立する二気の間を通す (例: 金木交戦 → 水で通関)。
4. **病薬 (びょうやく)**: 命局の「病」となる干支を除去する神を用神とする。

### 用神・喜神・忌神・仇神・閑神

| 名称 | 定義 |
| --- | --- |
| **用神** | 命局の主要な問題を解決する干支。 |
| **喜神** | 用神を生助する干支。 |
| **忌神** | 用神を剋制する干支。 |
| **仇神** | 忌神を生助する干支。 |
| **閑神** | 命局に大きな影響を与えない干支。 |

### 五行別 扶抑の対応

| 日主 | 身強のとき用いる | 身弱のとき用いる |
| --- | --- | --- |
| 甲乙 (木) | 火 (食傷)・金 (官殺)・土 (財) | 水 (印)・木 (比劫) |
| 丙丁 (火) | 土 (食傷)・水 (官殺)・金 (財) | 木 (印)・火 (比劫) |
| 戊己 (土) | 金 (食傷)・木 (官殺)・水 (財) | 火 (印)・土 (比劫) |
| 庚辛 (金) | 水 (食傷)・火 (官殺)・木 (財) | 土 (印)・金 (比劫) |
| 壬癸 (水) | 木 (食傷)・土 (官殺)・火 (財) | 金 (印)・水 (比劫) |

## 5. 十神の意味と作用 | Ten Gods

### 5.1 十神の吉凶両面

| 十神 | 順 (吉) | 逆 (凶) | 象意 |
| --- | --- | --- | --- |
| **正官** | 名誉・地位・規範 | 拘束・訴訟 | 職場・上司・夫 (女命) |
| **七殺** | 権威・武勇・決断 | 災難・敵・小人 | 権力・武職・情夫 |
| **正財** | 妻・正当な財 | 吝嗇・労苦 | 妻・給与・堅実な収入 |
| **偏財** | 商才・投機成功 | 浪費・情婦 | 父・愛人・臨時収入 |
| **正印** | 学問・母・保護 | 依存・停滞 | 学位・母・後援 |
| **偏印** | 才芸・宗教・偏才 | 孤独・食を奪う (梟神奪食) | 継母・特殊技芸 |
| **食神** | 楽天・食禄・子女 | 遊惰 | 表現力・子供 (女命) |
| **傷官** | 才華・技芸 | 官を傷つける・傲慢 | 芸能・反骨精神 |
| **比肩** | 独立・自我 | 分財・兄弟争い | 兄弟・友人・競争 |
| **劫財** | 行動力・剛毅 | 破財・劫奪 | 姉妹・ライバル・散財 |

### 5.2 位置による意味

四柱の位置 (宮位) と十神の組み合わせで意味が変わる。

| 柱 | 象徴する時期 | 主な象意 |
| --- | --- | --- |
| **年柱** | 0–15歳 / 祖先・幼年 | 出自・祖業・幼少期の環境 |
| **月柱** | 15–30歳 / 父母・青年 | 両親・兄弟・学業・職業選択 |
| **日柱** | 30–45歳 / 本人・配偶 | 自分自身・配偶者 (日支) |
| **時柱** | 45歳〜 / 子女・晩年 | 子女・晩年運・志望 |

## 6. 調候 (寒暖燥湿) | Climate Adjustment

『窮通宝鑑』の調候用神表と併用。三命通会も気候調整を重視。

### 基本原則

| 生まれ月 | 気候 | 好む五行 |
| --- | --- | --- |
| 亥子丑 (冬) | 寒 | **火** (温める) |
| 巳午未 (夏) | 燥・熱 | **水** (潤す) |
| 寅卯辰 (春) | 木旺・湿 | 火で発揚、金で剪定 |
| 申酉戌 (秋) | 金旺・燥 | 水で潤す、木で疏泄 |

### 例

- 冬生まれの丙火 → **甲木・丙火** を喜び、庚辛金を忌む。
- 夏生まれの庚金 → **壬水** を喜び、丁火を忌む。
- 春生まれの甲木 → **庚金** で剪定を喜ぶ。

## 7. 刑冲合会・空亡 | Interactions & Void

`getBaziDetail` の `刑冲合会` フィールドを参照。

### 三合・六合 (吉作用が多い)

| 種類 | 組み合わせ | 化する五行 |
| --- | --- | --- |
| **三合** | 申子辰 / 亥卯未 / 寅午戌 / 巳酉丑 | 水 / 木 / 火 / 金 |
| **半合** | 上記の隣接2支 | 同上 |
| **六合** | 子丑・寅亥・卯戌・辰酉・巳申・午未 | 土/木/火/金/水/(火土) |
| **天干合** | 甲己・乙庚・丙辛・丁壬・戊癸 | 土/金/水/木/火 |

### 冲・刑・害・破 (凶作用が多い)

| 種類 | 例 | 意味 |
| --- | --- | --- |
| **六冲** | 子午・卯酉・寅申・巳亥・辰戌・丑未 | 対立・変動・別離 |
| **三刑** | 寅巳申 / 丑戌未 / 子卯 (無礼刑) / 辰午酉亥 (自刑) | 刑罰・怪我・訴訟 |
| **六害** | 子未・丑午・寅巳・卯辰・申亥・酉戌 | 陰湿な妨害 |
| **相破** | 子酉・午卯・巳申・寅亥・辰丑・戌未 | 破壊・破財 |

### 空亡 (旬空)

日柱の旬 (甲子〜癸酉…) に含まれない2支が **空亡**。命局にある空亡支は、その柱の象意が虚しくなりやすい。ただし冲・合されると「填実 (てんじつ)」して復活する。

- **時柱**: 子女宮。透ける十神の強弱で子女運を見る。
- **月柱**: 父母宮・兄弟宮。

## 9. 神煞の運用 | Applying Shensha

詳細は [`shensha.md`](./shensha.md) を参照。三命通会での運用原則:

1. **十神・格局・用神を優先**、神煞は補助情報。
2. **吉神煞** (天乙貴人・天徳・月徳・文昌等) は用神を助けるとき最も効く。
3. **凶神煞** (亡神・劫煞・血刃・華蓋等) は忌神と重なると害が顕在化。
4. **貴人が空亡** → 効力減。**貴人が冲** → 反って動く可能性。
5. **大運・流年で神煞が発動** → その年に象意が現れる。

## 10. 大運・流年 | Decade Luck & Annual Luck

### 大運の見方

`getBaziDetail` の `大運` 配列を、以下の順で確認:

1. **干支の五行**: 用神・喜神を強めるか、忌神を強めるか。
2. **十神**: 大運の天干・地支蔵干の十神が命局とどう作用するか。
3. **命局との刑冲合会**: 大運支が命局支と合・冲・刑を形成するか。
4. **神煞の発動**: 大運支が命局の神煞発動条件を満たすか。

### 流年の見方

- 流年干支と命局・大運の三者関係を見る。
- **太歳** (流年支) を犯す (冲・刑・害) → 変動・災難の暗示。
- **用神が透ける流年** → 吉事の顕現年。

### 大運交替期

大運が切り替わる前後1–2年は動揺しやすい。特に忌神大運への切替は要注意。

## 11. 特殊格局 | Special Structures

日主が極端に旺・弱で、通常の扶抑理論が適用できない場合。

| 格局 | 条件 | 用神方針 |
| --- | --- | --- |
| **従旺格** | 日主が極旺、比劫印星のみ | 比劫・印星を用いる (順旺) |
| **従強格** | 印星が極旺 | 印星・比劫を用いる |
| **従児格** | 食傷が旺、財に流れる | 食傷・財を用いる |
| **従財格** | 財星が極旺、日主無根 | 財・食傷を用いる |
| **従殺格** | 官殺が極旺、日主無根 | 官殺・財を用いる |
| **化気格** | 天干合化が成立 (例: 甲己合化土) | 化した五行を用いる |
| **一行得気格** | 命局が一気に偏る (曲直・炎上・稼穡・従革・潤下) | 同気を用いる |

**注意**: 特殊格局の判定は厳密で、少しでも破格条件があれば通常格として扱う。
